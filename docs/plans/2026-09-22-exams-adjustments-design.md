# 考试、调休与翻页整改设计

用户于 2026-09-22 确认继续实施。

现有日历选周、三模式课表对比、WebVPN 入口已实现；保留并回归验证。考试和调休尚不存在。Android 已有历史 release APK，鸿蒙已有原生桥接和未签名 HAP，但迁移后的构建路径需要修复。

采用现有 Flutter 架构增量实现。每个 ScheduleDocument 增加独立 exams、adjustments 集合，缺省为空，保留旧 JSON 兼容。考试不进入 CourseSession，包含名称、日期、起止分钟、地点、座位和备注。调休以实际日期为唯一键，指向源教学周和星期；只在显示和对比时解析，不修改原始课程。同一天只能有一条规则，修改替换，删除恢复。

更多面板提供考试周和手动调休页面，记录按日期排序，支持新增、修改、删除，保存失败不关闭编辑器。列表明确当前课表范围。导出及复制保留独立数据，课程合并保留目标考试和调休，预览明确说明。

课表网格与比较复用按日期解析的课程来源，调休列显示来源提示。调休日不混入原日期的非本周课程；课程详情保持原课程身份，编辑仍作用于原课程。

翻页采用同一个 PageController 可视页状态，越过半页时更新顶部周次和日期；松手从实际位置继续，不先触发 cancel 的回弹。新手势中断当前动画并接管当前位置，定向短滑采用低阈值，快滑沿速度方向吸附。保留多指缩放与周数据缓存。
