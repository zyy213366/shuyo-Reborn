# ShuYo 第二版：1.1.0（Android build 2）

- 共同课程按所看周的真实日期、时间、教师、校区、地点及课程身份匹配，避免同课程号不同班误判。
- 首次使用默认浅色。新课表开启背景格子、多彩、教师、非本周课程、课程号和学分，显示所有课程周数；关闭课表控制栏。保留已有用户和导入课表的设置。
- 每次切周回顶部，包括返回看过的周。普通课表与课表对比共用此行为。

## 构建与签名

Android 版本 1.1.0+2；鸿蒙版本名 1.1.0、版本码 2（与 Flutter 打包后的实际值一致，上一版 HAP 为 1）。包名保持不变。

Android release 从本机 `android/key.properties` 读取 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`。`storeFile` 相对 android 目录。缺少配置时 Gradle 仅生成未签名 release，不能当作可安装升级包发布。

第二版保留第一版证书，SHA-256：`d5fb7b70c3ece16287cca7170814cc5045f0cda03d1d4302047101c4d60b1020`。该证书原为 Android Debug 证书，沿用是为了覆盖安装；本次没有将其冒充新生成的正式发布证书。现有密钥已另存到本机被 Git 忽略的 keystore，避免依赖自动生成的调试密钥。私钥和密码配置不能提交。

鸿蒙签名仍需华为账号的有效证书和 profile；本次版本号更新不代表已经获得签名。

## 验证

42 项直接相关测试通过，包含对用户提供的两份文件逐周验证（1–16 周）；静态分析无问题。原始课表仅在本机验证，未提交。

Android arm64 release APK 已生成并通过 apksigner 校验。与第一版包名和证书完全一致，实际 ABI 版本码由 2001 增加到 2002，符合覆盖升级条件；未进行真机安装验证。

本机 H 盘旧构建缓存发生目录访问错误，Android 改在 `D:/Huawei/shuyo-build/android-v2` 构建，并在该临时工程关闭 Kotlin 增量编译，以避免依赖缓存位于 H 盘时的跨盘路径异常。

鸿蒙第二版未签名 release HAP 已编译，并核实包内版本名、版本码。仍需有效华为签名才能安装到设备。
