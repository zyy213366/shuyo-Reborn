## 简介

ShuYo Reborn 是基于原项目继续开发的衍生版本。

这个项目主要希望改善课表的日常使用体验，并在原有功能基础上继续增加和完善一些适合上海大学学生使用的功能。

## 功能

在shuyo的基础上做了课程导入，考试周，多人课表空闲时间对比，优化了ui体验，支持滑动切换周次，优化了显示模式，支持通过缩放切换5天或7天的显示，支持调休的录入，支持显示教师，课程号，学嗯，非本周课程，支持自定义显示字体
部分功能仍在开发和完善中。

## 项目状态

项目目前仍处于开发阶段，功能和界面可能会继续发生变化。

## 安装

可以前往 Releases 页面下载已经构建好的版本。

## 开发

项目主要使用 Flutter / Dart 开发。

克隆项目：

git clone https://github.com/zyy213366/shuyo-Reborn.git

安装依赖：

flutter pub get

运行：

flutter run
