# 轻课表

面向上海大学的独立 Android 课表应用，基于 ShuYo 的课表界面和数据模型改编。本项目仅在本地开发，没有配置或推送到 ShuYo 的远程仓库。

## 功能

- 双指放大进入五天显示，缩小回到七天同屏；单指左右滑动翻周，点击课程查看详情。
- 左上角显示周数和本周状态，点击弹出居中的 1–16 周日历式选择表；圆圈标出现实本周，选中的周以实心背景显示。双击返回现实本周。周数下方显示日期范围，日期栏左侧显示周一所属月份。
- 更多面板使用滚轮切换课表；“显示背景格子”位于显示设置。背景隐藏后课程位置、空白格添加课程功能保持不变。
- “更多 → 显示设置”统一管理非本周课程、课程号、教师、多彩显示、背景格子、学分和课表控制栏。课程周数可选所有课程、仅非本周课程、不显示，按真实周次组合生成文字。非本周课程淡化，连续课程使用不透底的完整色块。
- 课程文字按卡片实际宽高自动换行；五天模式充分利用增加的宽度展示课程号、教师和地点，不改变课程节次或卡片高度。
- 显示设置支持全局浅色、深色、跟随系统、弹窗背景透明度，以及本机字体/内置 Noto Sans SC 字体切换；透明度拖动时实时预览，松手保存。
- 多课表、新建、重命名、切换、删除及独立副本。
- 更多 → 课表对比：勾选至少两张课表，回到首页周视图；共同课程高亮、其余变暗，共同空闲显示各课表占用时间的并集。按实际日期和各自作息对齐，空白区域即共同空闲。
- 学校登录统一使用上海大学 WebVPN，登录后读取课表。
- 更多 → 考试周：沿用 WebVPN，在考试安排页点击查询后导入；考试按独立周视图显示，重新导入更新同一场考试，保留本地座位和备注。支持手动补充、修改和删除。
- 更多 → 手动调休：指定实际日期执行某教学周、某星期的课程；首页与对比共用规则，删除恢复原安排。调休日以“·调”标识，长按日期可看来源；调休日编辑课程会明确操作源安排。开学前及学期后的调休日也能翻页查看。
- 翻页由同一可视页状态同步周数、日期和内容；松手继续当前偏移，下一次手势可接管进行中的动画，保留短滑翻页及多指缩放。
- 分享课表文件；通过系统“打开方式”或应用内文件选择器导入。
- 导入为新课表，或合并到已有课表；合并会去重并提示时间冲突。
- 手动编辑课程、设置开学日期、每节课时间、课程颜色及教师显示。
- 学校导入、手动编辑和文件分享保留可选课程号；旧文件缺少课程号仍可读取。课表显示偏好按课表保存，主题、字体与弹窗透明度按整个 App 保存，重启后恢复。
- 本地保存，无应用账号。导出文件不包含原始课表中的姓名、学号、班级字段。

## 使用

1. 安装 APK 后直接进入课表。右上角“更多”中上下滚动切换课表，停稳后立即生效；点击“管理课表”可新建、重命名、复制或删除。
2. 点击导入图标，选择上海大学官网，在学校页面完成登录并选好学期，点击“读取课表”。预览时确认第一周日期并保存。
3. 点击分享图标，将 JSON 课表文件发送给对方；接收者安装本应用后，可以用轻课表打开文件，也可以从应用内选择文件导入。
4. 导入预览可选择创建新课表或合并。合并要求开学日期、节次时间设置一致；冲突课程需确认后保存。
5. 单指左滑查看下一周，右滑查看上一周；双指缩放调整五天/七天显示，也可点击“5天/7天”按钮切换。五天模式点击“周一–周五”等范围按钮可调整可见日期。
6. 点击左上角周数文字，在居中的 1–16 周选择表中点击目标周；双击周数可回到现实本周。隐藏课表控制栏后，翻周和双指缩放手势仍可使用；需要查看周末时也可缩回七天显示。

文件格式为带版本号的 JSON，最大 2 MiB；目前支持本应用导出的文件，不保证兼容 WakeUp 或 ShuYo 的其他导出格式。课表副本与原件独立保存。

校园账号的真实登录和读取，需要有上海大学账号的使用者在手机上验证。自动检查使用匿名课表样例和模拟的官网响应。

## 本机字体兼容性

Android 12 及以上使用当前 Activity 的原生 TextView，通过公开 TextRunShaper / Font API 读取实际选中的中英文绘字字体，再加载至 Flutter 全局主题，包含卡片、标题、按钮、弹窗和 Cupertino 滚轮。应用回到前台或系统配置变化时重新检测，字体内容未变化则跳过重复加载；TTC 字体集合会提取选中的字面。字体仅在当前设备内存中使用，不复制到课表文件或上传。

Android 12 以下，或厂商不通过公开接口提供主题字体时，回退到 Flutter 系统字体。厂商私有主题、专用可变字体轴和系统进程缓存行为无法由通用接口完全覆盖，仍需对应品牌真机验证；不能保证所有主题商店字体均可同步。关闭同步则统一恢复内置字体。

## 开发与构建

环境：Flutter 3.47.4 / Dart 3.13.3、JDK 21、Android SDK 36，NDK 版本按 Flutter 配置安装。

```sh
flutter pub get
flutter test
flutter test tool/capture_home_test.dart
dart analyze lib test tool/export_test_fixture.dart
dart run tool/export_test_fixture.dart
node --test test/shu_script_test.cjs
flutter build apk --release --split-per-abi
```

Windows 本地工具包装脚本为 `tool/flutter.ps1`；其他机器可以直接使用自己安装的 Flutter。构建产物位于 `build/app/outputs/flutter-apk/`。当前 APK 使用本地开发签名，适合直接安装测试；正式发布前请配置并保管自己的签名密钥。

2026-09-23 本轮 release APK 已生成，通常手机使用 `app-arm64-v8a-release.apk`。同目录 `SHA256SUMS.txt` 记录哈希；已通过本次对比、翻页、考试相关测试和静态分析，APK 签名验证通过。上轮 x86_64 包已在 API 36 模拟器安装启动；本轮没有重复全量测试。当前机器签名与 9 月 18 日旧包不同，不能直接覆盖旧安装；请先在旧应用中逐张导出课表并妥善保存，再考虑更换安装。没有删除任何真实手机数据。

项目当前位于 exFAT 的 H 盘，Flutter batch 启动会显示 `Unblock-File ... Zone.Identifier` 提示；依赖重新解析后可继续运行，也可使用 `./tool/flutter.ps1 -CachedTool ...` 直接调用已初始化工具快照。SDK 迁移后需重新 `pub get`，不要复制旧 `.dart_tool` 路径索引。

可选的界面渲染检查使用实际内置字体，截图输出到 `build/previews/`。周数据与格子占用索引按需缓存，缩放时复用；远距离选周只绘制目标附近页面。实际设备帧率仍需在手机上用 profile 模式验证。
