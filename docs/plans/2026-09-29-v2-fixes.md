# ShuYo 第二版修复计划

目标：共同课程只高亮实际同一场课；首次使用默认浅色及开启显示选项（控制栏除外）；每次切周回到顶部，包括返回已看过的周。

设计：按实际日期、完整上课时间和课程代码/名称、教师、校区、地点确定共同课程。只比较正在查看的周，避免其他周或其他班的同名课程误亮。共同空闲继续取占用时间并集。

1. 用匿名课程字段复现同代码不同班的误判，覆盖真正共同课、不同日期/时间/教师/地点和三人对比。
2. 修复比较算法及当前周高亮；保留不同学期起始日的实际日期换算。
3. 修改新课表、显示服务及外观默认值；已有序列化设置不迁移。
4. 用户确认每次切周回顶部；统一普通课表和对比页面的纵向滚动重置，验证离开页面缓存范围后返回。
5. 版本递增为 1.1.0+2，鸿蒙同步版本；核对旧 APK 签名并保持升级兼容，禁止提交私钥。
6. 运行直接相关测试、分析和 Android release 构建，提交本次文件并推送 GitHub；保留之前鸿蒙构建未提交变更。
